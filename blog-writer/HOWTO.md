# 블로그 글 자동 작성 — 실행 가이드

채팅 없이 혼자 따라 할 수 있도록 정리한 문서입니다.

## 전체 흐름

1. 참고 블로그의 글 구조를 추출한다 (원문 문장은 저장되지 않음)
2. 구조 틀에 본문을 채운다 (Claude API 사용)
3. 틀을 미리보기 HTML로 만든다
4. 미리보기의 **본문 복사** 버튼으로 블로그 글쓰기 화면에 붙여넣는다
5. 직접 찍은 사진을 노란 표시 자리에 넣는다

## 0. 준비

### 0-1. 네이버 블로그 도메인 허용 (클라우드 세션인 경우)

1. 세션 제목바의 **클라우드 환경 이름** → **Edit**
2. **Network access** → **Allowed domains**에 `m.blog.naver.com` 추가
3. 저장

### 0-2. API 키 등록 (본문 자동 작성용)

1. 같은 **Edit** 화면에서 **Network secrets**(또는 **API credentials**)에 추가합니다. 없으면 환경 변수로 추가합니다.
   - 이름: `ANTHROPIC_API_KEY`
   - 값: Anthropic 콘솔에서 발급받은 키
2. 저장 후 **새 세션**을 엽니다. 기존 세션에는 적용되지 않습니다.
3. 확인:
   ```bash
   echo ${#ANTHROPIC_API_KEY}   # 0이 아니면 등록된 것
   ```

> 키는 채팅이나 파일에 직접 적지 마세요.

### 0-3. 패키지 설치 (로컬 PC에서 실행하는 경우)

```bash
pip install beautifulsoup4
```

## 1. 참고 블로그 구조 추출

```bash
cd blog-writer
python extract_post.py https://m.blog.naver.com/junjun526        # 최근 글
python extract_post.py https://m.blog.naver.com/junjun526/224448321722   # 특정 글
```

결과: `output/reference_structure.txt`

예시 내용:
```
제목: [제목 작성]

[문단: 약 3줄, 내용 작성]

[사진: 장면 설명]

[인용구: 강조할 한 줄]
```

## 2. 본문 자동 작성

### 방법 A: 주제만 주고 자동 작성

```bash
python write_post.py --topic "성수동 카페 후기" --photo-count 4 --style style.txt
```

- `--style`은 말투 참고 파일입니다 (선택). 예: 짧은 문장, 이모티콘 많이 등을 적은 텍스트 파일
- 생성된 초안은 `output/draft.txt`에 저장됩니다

### 방법 B: 구조 틀에 주제만 넣어 작성

현재 `write_post.py --topic`은 구조 틀을 입력으로 받지 않습니다. 구조를 반영하려면 `draft.example.txt`처럼 직접 초안을 쓰거나, 아래 단계로 확장해야 합니다 (필요하면 요청하세요).

### 방법 C: 직접 작성

`draft.example.txt`를 복사해서 내용을 바꾸고 아래 형식을 지킵니다.

- `제목: ...` (맨 윗줄)
- `# 소제목`
- `[사진: 설명]` → 사진 자리
- 빈 줄로 문단 구분

## 3. 미리보기 HTML 만들기

```bash
python write_post.py output/draft.txt
```

결과: `output/post.html` (브라우저로 열기)

## 4. 블로그에 붙여넣기

1. `output/post.html`을 브라우저에서 엽니다.
2. **본문 복사** 버튼을 누릅니다.
3. 네이버 블로그 글쓰기 화면의 본문에 `Ctrl+V` 합니다.
4. 제목은 따로 복사해서 제목 칸에 넣습니다.

## 5. 사진 넣기

- `[사진: ...]` 자리에 직접 찍은 사진을 에디터에서 넣습니다.
- 사진 파일을 `photos/` 폴더에 넣어 두면 미리보기에서 자리와 함께 볼 수 있습니다.
- HEIC 사진은 미리보기에 안 나올 수 있으니 JPG로 바꿔 쓰세요.
- 스티커, 지도, 링크는 에디터에서 직접 추가합니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `ANTHROPIC_API_KEY 환경 변수가 없습니다` | 0-2를 다시 확인하고 새 세션을 여세요 |
| 블로그 주소 접속 실패 (403) | 0-1에서 `m.blog.naver.com`을 허용하세요 |
| `공개된 글이 없습니다` | 블로그에 공개 글이 있는지, 주소가 맞는지 확인하세요 |
| 붙여넣은 서식이 깨짐 | 에디터에서 `Ctrl+Shift+V`(서식 없이 붙여넣기) 후 서식을 다시 적용하세요 |

## 주의

- 원문 문장을 그대로 옮기지 마세요. 구조와 말투만 참고하세요.
- 참고 블로그 사진은 쓰지 말고 직접 찍은 사진을 쓰세요.
- 과도한 자동 수집은 네이버 이용약관에 걸릴 수 있으니 개인 참고 범위에서 쓰세요.
