# SMS ↔ 카톡 브리지 (개인용, Android)

휴대폰으로 오는 문자를 카카오톡 방으로 넘기고, 그 방에 답장을 쓰면 문자로 보내 주는 앱입니다.
서버 없이 폰 한 대에서만 동작하며, 카카오톡 **알림**을 읽고 알림의 **답장 버튼**을 눌러 주는 방식입니다
(카카오톡 공식 API가 아니므로 카톡 업데이트로 동작이 바뀔 수 있습니다).

## 동작 구조

```
문자 수신 ─▶ 앱 ─▶ (봇 카톡 알림의 답장 액션) ─▶ 카톡 방 "내 계정 ↔ 봇 계정"
문자 발송 ◀─ 앱 ◀─ (봇 카톡에 뜬 알림 읽기)   ◀─ 내가 그 방에 쓴 "@번호 내용"
```

- **봇 계정**: 삼성 *듀얼 메신저*로 띄운 두 번째 카카오톡에 로그인한 별도 카카오 계정 (전화번호 또는 이메일 가입 계정).
- **내 계정**: 평소 쓰는 카카오톡. 봇 계정과 친구를 맺고 1:1 방을 만듭니다. 이 방이 "문자 콘솔"이 됩니다.
- 앱은 봇 카톡에 뜨는 알림만 봅니다. 내가 콘솔 방에 글을 쓰면 봇 카톡에 알림이 뜨고 → 앱이 읽어 문자 발송.
  문자가 오면 앱이 그 알림의 "답장" 액션을 재사용해 봇 명의로 방에 글을 씁니다.

## 설치 (갤럭시 S24 Ultra 기준)

1. **듀얼 메신저**: 설정 → 유용한 기능 → 듀얼 메신저 → 카카오톡 켜기 → 두 번째 카톡에 봇 계정으로 로그인.
2. 봇 카톡 설정에서 **알림 켜기 + 알림 내용 미리보기 켜기** (미리보기가 꺼져 있으면 내용을 읽을 수 없습니다).
3. 내 카톡에서 봇 계정을 친구 추가하고 1:1 방을 만든 뒤 아무 메시지나 1개 보냅니다.
4. 이 앱 APK 설치: 폰 브라우저에서 <https://lshrexgen-ai.github.io/sms-kakao-bridge/download/sms-kakao-bridge.apk>
   (저장소의 `sms-kakao-bridge/download/sms-kakao-bridge.apk`, GitHub Actions 아티팩트와 동일).
5. 앱 실행 → 버튼 1·2·3 순서대로 권한 허용
   - 알림 접근 허용 (설정 화면에서 "SMS 카톡 브리지" 켜기)
   - 문자·연락처·알림 권한
   - 배터리 최적화 제외
6. "최근 감지된 카톡 방" 목록에 `내이름 (user 95)` 처럼 뜨면, 그 이름을 **콘솔 방 이름**에 넣고 저장.
   `user 95`가 듀얼 메신저 쪽입니다. 메인 카톡(user 0)에 같은 이름의 방이 있으면 **프로필 ID 필터**에 95를 넣으세요.
7. 내 카톡에서 콘솔 방에 다시 메시지 1개 → 상태에 "카톡 답장 경로 ✅" → "테스트 메시지 보내기"로 확인.

추가로 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱과 **봇 카톡(듀얼)** 모두 "절전 예외"로 두세요.

## 사용법 (콘솔 방에 입력)

| 입력 | 동작 |
|---|---|
| `@01012345678 내용` | 그 번호로 문자 |
| `@홍길동 내용` | 연락처 이름으로 찾아 문자 |
| `내용` | 마지막으로 문자 보낸 사람에게 답장 |
| `/최근` | 마지막 발신자 확인 |
| `/도움` | 사용법 |

수신 문자는 `📩 이름 (번호)` 한 줄 + 본문으로 옵니다. 발송 후 `✅ 전송 → 번호`가 돌아옵니다.

## 주의

- 봇 카톡에서 콘솔 방을 **열어 둔 채로** 두면 알림이 뜨지 않아 앱이 메시지를 못 봅니다. 방을 닫아 두세요.
- 봇 카톡이 강제 종료되면 답장 경로가 사라집니다. 콘솔 방에 아무 메시지나 보내면 다시 잡힙니다 (대기 중인 문자는 자동 전달).
- MMS(사진·장문 MMS)는 받지 않습니다. 문자(SMS/LMS 연결 문자)만 처리합니다.
- Google Play 배포용이 아닙니다 (SMS 권한 정책상 개인 사이드로드 전용).

## 빌드

```bash
./gradlew assembleRelease
```

Android SDK 35, JDK 17 이상. release 빌드는 디버그 키로 서명되어 바로 설치됩니다.
